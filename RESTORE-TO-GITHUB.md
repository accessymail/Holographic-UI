2. Review `SOURCE-MANIFEST.sha256`.
3. Initialize or clone the target repository and place the files at repository root.
4. Verify the manifest before committing.
5. Commit the complete tree as one immutable restoration commit.
6. Push to `main` only after reviewing the diff.
7. Run GitHub Actions from the resulting commit.
8. Preserve the resulting commit SHA and workflow run IDs as release evidence.

# RC17.7 — Controlled Build Environment

## Purpose

RC17.7 defines a reproducible Linux build environment and a fail-closed environment qualification step. It does **not** claim that the application has been built or certified.

## Required evidence

Before production certification, the controlled environment must contain:

- Node.js 22.16.0
- npm compatible with the repository's engine constraint
- Rust/Cargo and Tauri prerequisites
- `package-lock.json` generated from the actual dependency graph
- `src-tauri/Cargo.lock` generated by Cargo
- clean dependency installation
- TypeScript/type checking results
- complete unit/integration test results
- production web build output
- Rust tests and Tauri native build output
- exact tool versions and artifact hashes

## Fail-closed rule

`scripts/qualify-build-environment.mjs` exits non-zero whenever a required prerequisite is missing or does not match the declared contract.

The current development/container definition is an environment contract. It is not itself build evidence and must not be represented as certification.

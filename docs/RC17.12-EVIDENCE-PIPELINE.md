# RC17.12 — Release Evidence Pipeline

This release adds deterministic evidence-generation and verification for SBOM and build provenance.

## Important boundary

`declared-dependencies.sbom.json` is a **declared-dependency SBOM**, not an exact build SBOM. Until package-lock.json and Cargo.lock exist and a controlled build executes, it must not be represented as the dependency graph actually used to produce a release artifact.

`build-provenance.json` records available source/toolchain/material metadata. It does not constitute SLSA provenance or a signed attestation. A CI runner must generate authoritative provenance after the actual build.

## Commands

- `npm run generate:sbom`
- `npm run verify:sbom`
- `npm run generate:provenance`
- `npm run verify:provenance`

The certification gate remains fail-closed until exact dependency resolution, build execution, signing, and attestation evidence are present.

# Enterprise Certification Contract

## Status

**NOT CERTIFIED.** This document defines the evidence contract required before a Holographic UI release may be described as production-grade or enterprise-secure.

## Mandatory evidence

1. Immutable source commit and reviewed change history.
2. `package-lock.json` and `src-tauri/Cargo.lock` generated by the supported toolchains.
3. Clean `npm ci --ignore-scripts` installation.
4. Successful TypeScript checks, unit tests, production build, and protocol validation.
5. Rust/Tauri compilation and native-boundary qualification on each supported platform.
6. Static security, secret scanning, dependency/SCA, and CodeQL results with no release-blocking findings.
7. Native capability authorization, session binding, expiry, nonce replay protection, rate limiting, and fail-closed behavior.
8. OS-level sandboxing and privilege separation evidence; application flags are not accepted as proof.
9. IPC fuzzing and malformed-input testing.
10. SBOM generated from the exact release source/build.
11. Build provenance/attestation tied to the exact release artifact.
12. Signed release integrity metadata.
13. Cross-platform qualification.
14. Vulnerability register showing remediation or accepted risk with explicit ownership and expiry.
15. Independent penetration/security assessment.

## Certification rule

Automated CI is necessary but not sufficient. A release remains **NOT CERTIFIED** until all mandatory evidence is present and independently reviewable.

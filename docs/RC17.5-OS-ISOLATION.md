# RC17.5 — OS Isolation Hardening

## Scope

RC17.5 establishes the production deployment contract for OS-level isolation and removes the remaining ambiguity between application-level sandboxing and true OS enforcement.

## Implemented in this release

- Versioned platform-isolation contract.
- Required release-evidence schema.
- Deployment sandbox documentation.
- CodeQL workflow pinned to the verified v4.38.0 commit.
- Release version advanced to `1.0.0-rc.17.5-os-isolation`.

## Not claimed

This release does **not** claim that Windows AppContainer, macOS sandboxing, Linux namespaces/seccomp/AppArmor, or equivalent privilege separation has been implemented and tested. Those require native platform qualification on their respective operating systems.

## Release gate

`privilege_separated` must remain false until platform-specific evidence exists. A production certification must reject any target without a validated OS isolation profile.

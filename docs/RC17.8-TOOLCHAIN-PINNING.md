# RC17.8 — Controlled Toolchain Pinning

## Purpose

RC17.8 makes the native build environment deterministic at the toolchain layer. It does not claim that dependency resolution, compilation, tests, or release certification have passed.

## Pinned toolchain

- Node.js: `22.16.0` via the controlled build container.
- Rust: `1.98.1` via `rust-toolchain.toml`.
- Rust components: `rustfmt`, `clippy`.
- Linux target: `x86_64-unknown-linux-gnu`.

Rust 1.98.1 is a released stable Rust toolchain; the exact version is recorded rather than using `stable` so future toolchain changes cannot silently alter the build environment.

## Bootstrap behavior

`scripts/bootstrap-controlled-build.mjs` attempts to generate the real lockfiles. It never writes fabricated dependency metadata. If registry access or Cargo is unavailable, the command exits non-zero and records the blocked state in `controlled-build-bootstrap.json`.

## Certification rule

A lockfile is valid release evidence only when generated by the package manager from the actual manifest in the controlled environment and subsequently committed/reviewed as source.

# RC17.10 — CI Native Build Qualification

## Purpose

RC17.10 adds the first CI workflow that can produce real native build evidence.
It deliberately fails before dependency installation when the required lockfiles are absent.

## Required evidence

- `package-lock.json`
- `src-tauri/Cargo.lock`
- exact Node 22.16.0 runtime
- repository-pinned Rust toolchain from `rust-toolchain.toml`
- `cargo check --locked`
- `cargo test --locked`
- `cargo clippy --locked --all-targets -- -D warnings`
- TypeScript typecheck
- Vitest suite
- production web build
- Tauri production build
- immutable commit SHA and toolchain evidence

## Certification rule

A successful workflow run is build evidence for that commit only. It does not by itself certify the product as enterprise-secure. Security, isolation, fuzzing, SBOM, provenance, signing, cross-platform and independent assessment gates remain mandatory.

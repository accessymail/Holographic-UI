# RC17.9 — Dependency Integrity Gate

## Objective

Prevent release certification until the exact npm and Cargo dependency graphs used by the build are recorded and verified.

## Required evidence

1. `package-lock.json` with lockfile version 3.
2. `src-tauri/Cargo.lock` generated by the pinned Rust toolchain.
3. Every direct npm dependency must match the declared version in `package.json`.
4. Cargo must be executed with `--locked` for qualification.
5. The release version must be identical across package, Tauri configuration, VERSION, and RELEASE metadata.
6. Final SBOM and provenance must be generated from the exact built artifact, not from declarations alone.

## Fail-closed rule

Missing lockfiles produce `BLOCKED`; inconsistent versions or dependency declarations produce `FAIL`. Neither state may be certified as production-ready.

# Production Readiness

RC16 is the engineering baseline. RC17 is the hardening and certification track.

## Current blocking work

- deterministic npm and Cargo lockfiles
- independent native capability authorization
- native replay/rate limiting
- OS sandboxing and privilege separation
- filesystem race resistance
- IPC fuzzing and negative testing
- complete CI security pipeline
- reproducible builds
- exact-build SBOM and provenance
- cross-platform qualification
- independent penetration testing

Do not label the project production-certified or enterprise-secure until every mandatory release gate is evidenced.

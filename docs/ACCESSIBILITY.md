# Accessibility

Holographic styling is not an accessibility mechanism. Every important operation must have a non-gesture path.

Required baseline:

- keyboard navigation and visible focus
- semantic headings, controls and status announcements
- sufficient text/background contrast
- reduced-motion support
- scalable text and responsive layouts
- non-camera fallback for gesture actions
- errors and approval decisions that are understandable without animation

Verify with automated accessibility checks and manual keyboard/screen-reader review on each supported UI platform.
